SMP-Video from the SMP Challenge (smpchallenge/SMP-Video on Hugging Face, gated): short TikTok-style videos posted between Jan 2022 and Aug 2023. Only the train split has labels, so the 1,500 rows used here are the first 1,500 of its 4,000 labelled posts, split 1,000 / 500 with a seeded shuffle. The raw target popularity is a continuous score (1.22–13.35, median 8.75). PolicyInduction predicts YES/NO, so the label is YES for the top 10%: popularity ≥ 11.55, the train 90th percentile, applied unchanged to test. That leaves 100 YES in train and 59 in test (11.8%). The videos themselves are not used.

2  How the test is implemented

StepDetail
RowsFirst 1,500 labelled train rows, seeded shuffle (seed=0) → 1,000 / 500
LabelYES = popularity ≥ 11.55 (train 90th percentile) → 100 / 59 YES
TrainAll 1,000 training rows
TestAll 500 rows — identical for every model
Inputs18 columns: caption, suggested words, country, language, time, 7 user counts, video size and duration, music. Dropped: pid, uid, vid, video_path, video_format
BaselinesLogistic regression and gradient boosting; counts log-scaled, categories one-hot, free text TF-IDF; fixed 0.5 cut
Encodingsklearn: features above  ·  PolicyInduction: column: value text

Both methods receive the same columns. One mismatch: the baselines currently ignore post_time (it becomes a string no transformer picks up), while PolicyInduction sees it. Also, 5 users have negative like/heart counts; the baselines clip them to 0, PolicyInduction sees the raw values.

Identical settings gave F0.5 from 0.24 to 0.46, mostly because the chosen threshold moves (0.20–0.54). The 10-policy run that scored best (F0.5 0.46) was the first; its two repeats scored 0.34 and 0.32, so that advantage did not hold. ROC-AUC is steadier (0.78–0.82) and sits below logistic regression on all columns (0.84). The content-only baselines lose about 0.14 AUC, so account size carries most of the signal; PolicyInduction has not been run content-only yet.
