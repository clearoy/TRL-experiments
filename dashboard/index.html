What is being tested

PolicyInduction writes natural-language rules from labelled examples, has a second model answer each rule YES or NO for every sample, and fits an L1 logistic regression on those binary answers. The output is a small set of human-readable policies with weights, rather than an opaque model.

generate policies→ score each policy × sample→ binary matrix→ L1 logistic regression→ prediction
