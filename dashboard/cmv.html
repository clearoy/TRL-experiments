Tan et al. 2016, the pair task from the Cornell ChangeMyView corpus v1.0. On /r/ChangeMyView a user posts a view and invites others to argue against it; if a reply changes their mind, the poster awards it a delta. Each example pairs two replies to the same post — one that earned a delta, one that did not — selected as the two most lexically similar root replies. The task is to pick the winner.

The split is temporal, not random: training covers 2013-01-01–2015-05-07 and heldout 2015-05-08–2015-09-01. No post appears in both.

Why the pairing matters

Both replies answer the same person, the same stated view, the same topic. The subject matter therefore cannot separate them, and neither can anything that depends on the post alone. Only how each reply argues is left.

Winning replies are longer — 190 median words against 155 — so “pick the longer one” alone scores 0.5967. root_truncated is the control for that: with both sides at identical word counts a length guesser is forced to exactly 0.5000, and the preparation scripts abort if it is not.

How PolicyInduction consumes a pair

One row per pair, carrying both replies. Which reply lands in slot A is randomised 50/50, so position carries no information, and the label names the winner.

Identical machinery to the COMPAS run. The only structural difference is that a policy here compares two texts rather than describing one, and the decision cut is fixed at 0.50 because swapping the replies must flip the answer.

Their features are countable surface quantities, no embeddings. Interplay measures word overlap between reply and post over three vocabularies (stopwords, content words, all) — four quantities each. Style covers articles, sentiment words, hedges, pronouns, links, formatting, and readability. We reimplemented both from the paper's description (tan_paper/) — not a verified reproduction, since LIWC and the paper's word-norm lexicons are proprietary and were substituted or omitted, but close enough to use as a feature source in its own right.

Their evaluation set is the same 807 heldout pairs used here, and this repo's word-count baseline reproduces their number to 0.5967 / 0.6543 / 0.5000 across the three conditions — the check that the data preparation is correct. Their classifier compares the two replies as a pair and is fitted on all 3,456 training pairs, so it is a reference point rather than a budget-matched competitor.

2  How the test is implemented

StepDetail
FormulationOne row per pair; label YES means argument_A won
Slot assignmentRandomised exactly 50/50, so position carries no signal
Train500 pairs, stratified, nested draw — the LLM budget
TestAll 807 heldout pairs — identical for every method
DecisionProbability > 0.50. Not the fitted F-beta threshold: swapping the two replies must flip the answer, and only a 0.50 cut respects that
Positional controlEvery pair scored in both orders and averaged; pairs where both orders name the same slot score 0.5
MetricPairwise accuracy, ties 0.5

The two replies are never shown for a holistic side-by-side judgement without the swap control. Scored in one order only, a model can name the same slot regardless of which reply sits there; averaging both orders removes that.

The vanilla-LLM row asks the model directly — no induced rules, no policy list, one prompt per pair: “which reply is more persuasive?” Unlike every other row it is scored in a single order, no swap, so it always commits to an answer and carries no protection against positional bias.
